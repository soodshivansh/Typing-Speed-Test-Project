# 🐼 PANDA TYPE - Typing Speed Test

A Python-based typing speed test application built with Tkinter that helps users measure and improve their typing speed in words per minute (WPM).

## ✨ Features

- **Real-time Typing Test**: 60-second typing challenge with live feedback
- **WPM Calculation**: Accurate words per minute measurement
- **Visual Feedback**: Color-coded text showing typed and remaining characters
- **Multiple Test Passages**: Random selection from various text samples
- **Retry Option**: Instantly restart the test to improve your score
- **User-friendly Interface**: Clean and intuitive GUI design

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Tkinter (usually comes pre-installed with Python)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/soodshivansh/Typing-Speed-Test-Project.git
```

2. Navigate to the project directory:
```bash
cd Typing-Speed-Test-Project
```

3. Run the application:
```bash
python "typing speed.py"
```

## 🎮 How to Use

1. **Launch** the application
2. Click the **START** button to begin the typing test
3. **Type** the displayed text as quickly and accurately as possible
4. The test runs for **60 seconds**
5. View your **WPM score** at the end
6. Click **Retry** to take the test again
